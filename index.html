webOS never stopped.

LuneOS carries Palm's operating system onto current hardware — the card multitasking, the gestures, Luna itself — rebuilt on an open stack. Test images are still being built — the most recent in September 2026.

What it is built on

LuneOS is assembled with Yocto, combining Palm and LG's open webOS components with a current Linux userspace.

device base
Halium 16.0, or mainline Linux
components
webOS OSE 2.25
toolkit
Qt 6.12
browser engine
Chromium 151
build system
Yocto 6.0

Take part

The project is built by a small group of people in their own time. New device ports usually start with someone owning the hardware and getting curious.

WikiBuild instructions, device pages and project documentation. SourceEvery component, build recipe and device tree on GitHub. IRC#webos-ports on Libera.Chat, where most development talk happens. TelegramThe LuneOS Developer Community channel. ForumsAsk questions and follow testing threads at webOS Lives. PivotCERelease write-ups and news from the wider webOS community.

Send a message

For anything that does not fit a chat room — hardware offers, press questions, or a port you would like to work on. It reaches the same people.
